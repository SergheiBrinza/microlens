## 1. Summary in plain language

MicroLens is designed so that **the only personal data the application sees is what you point your camera at, and that data never leaves your device unless you explicitly choose to share it**. The application itself does not collect telemetry, analytics, identifiers, or user accounts. There is no advertising. There is no monetisation. There is no profiling.

| What | Status |
|---|---|
| User accounts / login | None. The app does not ask for any credentials |
| Telemetry, analytics, crash reports | None. No third-party SDKs are bundled |
| Background data collection | None |
| Camera images / captured photos | Stored only locally on your device, in app-private storage |
| Inference (model output) | Computed entirely on-device. Text never leaves your phone |
| Network requests | Limited to one purpose: downloading model weights from Hugging Face on first launch (see §3) |
| Cookies / tracking | Not applicable to the Android app. The browser-based demo on Hugging Face Spaces is governed by Hugging Face's privacy policy. |

## 2. Personal data and Article 4(1) GDPR

GDPR Article 4(1) defines personal data as "any information relating to an identified or identifiable natural person". MicroLens is built so that the application itself processes **no personal data** in the sense of GDPR.

The categories of data the application interacts with are:

- **Microscopy images.** Captured by the device camera or imported from the gallery. These are pictures of cells, water samples, and similar specimens. They do not contain personally identifying information unless the user deliberately points the camera at, e.g., a face or a document. Such atypical use is outside the intended purpose of the application; the user remains the sole controller of the device camera.
- **Inference results.** Short scientific descriptions generated by the on-device model.
- **Application-internal logs.** Stored only in Android's per-app log buffer; not transmitted off-device.

**Lawful basis under GDPR Art. 6(1):** No personal data processing takes place under the controller's responsibility, so no lawful basis is required. To the extent any incidental personal data is captured (e.g. a face accidentally in frame), the user is the sole controller and processor; MicroLens has no access to that data after the camera frame leaves the application.

## 3. Network requests: model download

On first launch, MicroLens offers to download the GGUF model weights from Hugging Face. While the MicroLens Final weights are still in training, the application falls back to the base Gemma 4 E2B GGUF (≈ 3 GB):

```
https://huggingface.co/unsloth/gemma-4-E2B-it-GGUF/resolve/main/...
```

Once the MicroLens Final weights are published, the same download path will be repointed at:

```
https://huggingface.co/Laborator/microlens-final/resolve/main/gguf/...
```

This is a **plain anonymous HTTPS download**. No user identifier is sent. Hugging Face will, as any web server does, see the IP address of the requesting device; that is governed by [Hugging Face's privacy policy](https://huggingface.co/privacy).

After download, the model files live in app-private storage and the application makes no further network calls. **Inference is fully local.** You can verify this by toggling the device into airplane mode after download; the application continues to function as designed.

## 4. Permissions requested

| Permission | Why | Can you deny? |
|---|---|---|
| `CAMERA` | To capture microscopy frames through the lens | Yes, but the application becomes view-only without it |
| `INTERNET` | One-time model download on first launch | Yes, but you must then sideload the model files via ADB |
| `WRITE_EXTERNAL_STORAGE` (Android ≤ 9 only) | Save captures to gallery | Yes |

The application requests no other permissions. There is **no microphone**, **no contacts**, **no location**, **no SMS**, **no phone state**, **no Bluetooth**, **no advertising ID** access.

---

## 5. Data retention

- **Captured images** are stored in your device's local gallery under `Pictures/MicroLens/`. They are deleted when you uninstall the application or manually delete them.
- **Model weights** are stored in `Android/data/com.kilabor.microlens/files/models/`. They are deleted when you uninstall.
- **No server-side retention.** There is no server.

---

## 6. Children's data

MicroLens does not knowingly target users under the age of 13 (16 under GDPR Recital 38 in some Member States). Because the application processes no personal data, there is no requirement for parental consent under GDPR Art. 8.

---

## 7. International transfers

Because the application stores nothing on remote servers and processes everything locally, **there is no international transfer of personal data** under GDPR Chapter V.

The single network request (model download) fetches a static asset from Hugging Face. It does not transfer user data outward. Hugging Face's own data handling is governed by their privacy policy.

---

## 8. Your rights under GDPR

Because MicroLens does not process personal data, the rights of access (Art. 15), rectification (Art. 16), erasure (Art. 17), restriction (Art. 18), portability (Art. 20), and objection (Art. 21) **do not apply** to this application: there is nothing for the maintainer to retrieve, correct, or delete on your behalf, because the maintainer holds nothing.

To delete all data the application stored locally on your device, simply uninstall the application.

---

## 9. Security

- All inference is **on-device**. Model weights and captured images never leave the phone unless you explicitly export them.
- HTTPS is enforced for the model download.
- The application is published as a debug-signed APK on GitHub Releases. The signing certificate is generated locally; it is not associated with any individual identifier.
